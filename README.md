# Алгоритмы сортировки

В данном репозитории представлены реализации различных алгоритмов сортировки. Ниже приведено описание принципа работы каждого из них.

## 1. Пузырьковая сортировка (Bubble Sort)
**Принцип работы:** Алгоритм многократно проходит по массиву, сравнивая соседние элементы. Если текущий элемент больше следующего, они меняются местами. Таким образом, самые большие элементы постепенно «всплывают» в конец массива, подобно пузырькам воздуха. Проходы повторяются до тех пор, пока массив не будет отсортирован.
* **Сложность:** $O(n^2)$

## 2. Сортировка выбором (Selection Sort)
**Принцип работы:** Массив условно делится на две части: отсортированную и неотсортированную. На каждом шаге алгоритм находит минимальный элемент в неотсортированной части и меняет его местами с первым элементом неотсортированной части. Таким образом отсортированная часть постепенно увеличивается.
* **Сложность:** $O(n^2)$

## 3. Сортировка вставками (Insertion Sort)
**Принцип работы:** Алгоритм перебирает элементы массива один за другим и каждый новый элемент вставляет на подходящее место среди ранее отсортированных элементов. Это похоже на то, как люди обычно сортируют карты в руках.
* **Сложность:** $O(n^2)$ (в лучшем случае $O(n)$)

## 4. Быстрая сортировка (Quick Sort)
**Принцип работы:** Основан на парадигме «разделяй и властвуй». Выбирается один элемент массива, называемый *опорным* (pivot). Затем массив перераспределяется так, что все элементы меньше опорного оказываются до него, а все элементы больше — после. Далее алгоритм рекурсивно применяется к подмассивам слева и справа от опорного элемента.
* **Сложность:** В среднем $O(n \log n)$, в худшем случае $O(n^2)$

## 5. Сортировка слиянием (Merge Sort)
**Принцип работы:** Также использует подход «разделяй и властвуй». Массив рекурсивно разбивается пополам до тех пор, пока каждый подмассив не будет состоять из одного элемента. Затем эти подмассивы попарно сливаются в новые отсортированные массивы, пока не будет собран один итоговый отсортированный массив.
* **Сложность:** $O(n \log n)$

## 6. Пирамидальная сортировка / Сортировка кучей (Heap Sort)
**Принцип работы:** Сначала элементы массива организуются в структуру данных, называемую невозрастающей пирамидой (max-heap), где родительский узел всегда больше своих потомков. Корень пирамиды (максимальный элемент) меняется местами с последним элементом массива. Затем размер кучи уменьшается на 1, и структура кучи восстанавливается. Процесс повторяется, пока куча не опустеет.
* **Сложность:** $O(n \log n)$

## 7. Сортировка подсчетом (Counting Sort)
**Принцип работы:** Не использует сравнения элементов напрямую. Работает только для целых чисел в известном диапазоне. Алгоритм подсчитывает количество вхождений каждого числа в исходном массиве, сохраняя эти данные во вспомогательном массиве. Затем на основе этих подсчетов вычисляются позиции каждого элемента в итоговом массиве.
* **Сложность:** $O(n + k)$, где $k$ — диапазон значений.

## 8. Поразрядная сортировка (Radix Sort)
**Принцип работы:** Обрабатывает элементы (обычно числа или строки) по разрядам, начиная с младшего (LSD) или старшего (MSD). Для сортировки по каждому разряду используется стабильный алгоритм сортировки (часто Сортировка подсчетом). После прохода по всем разрядам массив оказывается полностью отсортирован.
* **Сложность:** $O(d \cdot (n + k))$, где $d$ — количество разрядов.
